How a feature selection becomes a validated suite of test cases. Truth flows from the Compiler · reasoning from Claude · every result is validated before it is trusted.

3 CLAUDE  —  the reasoning engine  (manual copy / paste)

Paste prompt into Claudegoverned by the Skills layer — use only injected knowledge, never invent facts
→
Claude proposes test caseswhich scenarios, which values, which assertions — returns a JSON array
→
Paste JSON backinto QA Studio (or load a .json file)
Why: Claude is used only for reasoning — it is never the source of truth. No server or API key keeps the tool zero-cost and zero-setup.
▼

4 VALIDATE & DELIVER

Validation engineAJV vs the OpenAPI schema  +  the business rules
→

→
⬇ Export CSVExcel-ready hand-off to test-management tools
Why: this is the credibility step — every AI-generated payload is verified against the real schema & rules before a human trusts it. "Verified valid," not "probably valid."
↺ Feedback loop: the Coverage matrix's gaps feed back into the next prompt as priorities — so each round targets what is still missing.
